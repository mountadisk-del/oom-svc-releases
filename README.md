# oom-svc

预编译的静态二进制（x86_64 Linux, musl），见 [Releases](https://github.com/mountadisk-del/oom-svc-releases/releases)。

```sh
curl -LO https://github.com/mountadisk-del/oom-svc-releases/releases/latest/download/oom-svc-x86_64-linux-musl
curl -LO https://github.com/mountadisk-del/oom-svc-releases/releases/latest/download/oom-svc-x86_64-linux-musl.sha256
sha256sum -c oom-svc-x86_64-linux-musl.sha256
chmod +x oom-svc-x86_64-linux-musl
```
